## Interview 1

**Recording link**: [Listen to Interview 1](https://uq.sharepoint.com/:u:/r/teams/Section_7620_22283/Shared%20Documents/54_Richard/Iteration%202_Round_Interview%201_Adyo%20Arkan%20Prawira.m4a?csf=1&web=1&e=UYsE9Y)

| Questions | Responses |
|----------|-----------|
| Where would you expect a “Support & Well-being” button on Blackboard? | Somewhere visible like the top menu or main dashboard so it’s easy to access. |
| What would you expect that button to do? | Direct me to mental health resources or counseling support options. |
| Would Blackboard feel like a natural place for well-being support? | It feels unexpected since I usually associate Blackboard with academics only. |
| What would you think of a page with community stories, chat, and emergency resources? | It seems like a central hub for mental health support and guidance. |
| Which option would you click first and why? | Chat with someone because it feels more immediate and helpful. |
| Does the layout feel clear? | Yes, it’s simple and easy to understand. |
| How comfortable are you reading anonymous student posts? | Fairly comfortable, but it depends on the content quality and relevance. |
| Would read-only or interactive feel better? | Read-only feels safer and less pressure to engage. |
| Would it make you feel less alone? | Yes, it shows others are going through similar experiences. |
| How easy would posting anonymously be? | Still difficult due to fear of judgment, even if anonymous. |
| Would topic tags help? | Yes, it helps organize thoughts and express issues better. |
| How important is anonymity? | Very important—I wouldn’t post without it. |
| Would you use a private chat without booking? | Yes, it’s easier and faster than formal appointments. |
| What makes chat feel safe or unsafe? | Safe if anonymous and confidential; unsafe if privacy isn’t guaranteed or responses are slow. |
| Would late-night chat help? | Yes, especially if it’s available 24/7. |
| Where should emergency resources be? | At the top as a visible red button. |
| What wording builds trust? | Clear labels like “Emergency Hub” or similar direct wording. |
| How to recognize urgent help quickly? | Strong colors like red, bold text, and large buttons. |
| Would you trust the university platform? | Yes, more than random websites. |
