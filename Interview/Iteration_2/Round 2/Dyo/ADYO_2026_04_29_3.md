| Questions | Responses |
|----------|-----------|
| Where should the support button be located? | Somewhere easy to access, like a main navigation area. |
| What should it contain? | Information about support services and helpful articles. |
| Is Blackboard expected for support? | Not really—it’s mainly for academic use, so it feels surprising. |
| What does the 3-option page represent? | Different support pathways depending on needs. |
| Which option first? | Reading community stories to understand others’ experiences first. |
| Is the layout clear? | Yes, it feels straightforward. |
| Comfort reading anonymous posts? | Somewhat comfortable, as long as it’s not too personal. |
| Read-only or interactive? | Read-only is preferred for safety and privacy. |
| Does it reduce loneliness? | Yes, it helps to see shared experiences. |
| Posting anonymously easy? | Easier than normal posting, but still not completely comfortable. |
| Do tags help? | Yes, they help structure expression and thoughts. |
| Importance of anonymity? | Very important to feel safe sharing. |
| Preferred support type? | Professional support is still important alongside peer support. |
| What makes chat safe? | Privacy and feeling that interactions are controlled and respectful. |
| Would support help during stress (e.g., financial)? | Yes, having options available is helpful. |
| Where should emergency resources be? | Within the support section, clearly labeled. |
| What wording builds trust? | Clear references to health and emergency support. |
| How to quickly identify urgent help? | Features like live chat or instant response indicators. |
| Trust university platform? | Yes. |
