## Interview 2

**Recording link**: [Listen to Interview 2](https://uq.sharepoint.com/:u:/r/teams/Section_7620_22283/Shared%20Documents/54_Richard/Iteration%202_Round%202_Interview%203_Adyo%20Arkan%20Prawira.m4a?csf=1&web=1&e=6OLqax)

| Questions | Responses |
|----------|-----------|
| Where should the “Support & Well-being” button be located? | In the main menu, where everything else is, so it’s easy to find without clicking around. |
| What should it do? | Show a list of support resources in one place, including mental health and study support, so I don’t have to go to different websites. |
| Would Blackboard feel natural for support? | Not really. I usually associate Blackboard with academic work, which is often the source of stress itself. |
| What does the 3-option page represent? | It feels like a support center with different levels of help—reading, talking to someone, or handling emergencies. |
| Which option would you click first and why? | Community stories, because it’s the easiest and least stressful. I’d rather understand others first before talking. |
| Is the layout clear? | Yes, it’s clear and easy to understand. |
| How comfortable are you reading anonymous posts? | Very comfortable. It feels normal, like reading Reddit and seeing what others are going through. |
| Would read-only or interactive feel better? | Read-only. Comments can become toxic, and I just want to read without engaging. |
| Would it make you feel less alone? | Yes, because it shows that other people are also struggling even if they seem fine externally. |
| How easy would posting anonymously be? | Still difficult, even if anonymous, because sharing personal struggles is hard. |
| Would topic tags help? | Yes, it helps organize thoughts and makes the problem feel more manageable. |
| How important is anonymity? | Extremely important. I wouldn’t post at all if my name was attached. |
| Would you use a private chat without booking? | Very likely. Booking makes it harder to reach out. |
| What makes chat feel safe or unsafe? | It feels less intimidating than formal counseling. It needs to feel private and not visible to others like professors. |
| Would late-night chat help? | Yes, because that’s when stress usually hits the most. |
| Where should emergency resources be? | At the very top so it’s immediately visible without searching. |
| What wording builds trust? | Short, direct phrases like “Get Help Now” or “Call Now.” |
| How to recognize urgent help quickly? | A red button or something visually strong that clearly signals emergency. |
| Would you trust the university platform? | Yes, because it should provide accurate and reliable contacts like campus security and health services. |
