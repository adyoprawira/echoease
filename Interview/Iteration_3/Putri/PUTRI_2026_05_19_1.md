## Interview 1

**Recording link**: [Listen to Interview 1]()



| **Question** | **Answer** |
| --- | --- |
| If you were stressed today, what would be the first thing you click on? | I would probably go to the resources section first, since that’s where I’d expect to find something helpful or calming. It feels like the most direct place to look for support when I’m overwhelmed. |
| Does the interface feel clean and easy to navigate? | Overall, yes — it looks clean and simple. But at times it feels a bit confusing because there’s no clear way to return to the previous page, so I get stuck and don’t know where to go next. |
| Would you feel safe posting anonymously in the community forum? | Not really. I’d be worried that someone could hack into my account or somehow trace the post back to me. Because of that, I wouldn’t feel comfortable sharing my own concerns publicly. |
| Would you still browse the community stories even if you don’t want to post? | Yes, I’d still read through other people’s posts. It helps to see if anyone else is going through something similar, and it might make me feel less alone even if I don’t contribute myself. |
| Does the emergency resources section feel urgent enough? | Yes, the bold text makes it stand out immediately. It was one of the first things I noticed on the page, so it does give a sense of urgency and importance. |
| Any features you wish the prototype had? | A back button would be really helpful. Sometimes I click into a page and then can’t figure out how to return to where I was before, which makes navigation feel a bit limited. |
